# Bored Box

A chunky little arcade of simple browser games for when you're bored.

## Games

- **Snek** — classic snake
- **Matchup** — memory pairs
- **Xs & Os** — tic-tac-toe vs a basic AI
- **Zap** — reaction timer
- **2048** — slide and merge

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
